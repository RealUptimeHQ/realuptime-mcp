# Contributing

This repository is documentation only: a README and install notes for the
hosted server at https://mcp.realuptime.io. The server's code is not in this
repository.

- **Issues are welcome** for anything wrong or missing in the docs, and for
  problems connecting a client to the server. Name the client and its
  version, the endpoint you used and what happened, with API keys removed.
- **Pull requests that fix the documentation are welcome.**
- Security problems are not reported in public issues; see
  [SECURITY.md](SECURITY.md).
